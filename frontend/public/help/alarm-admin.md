# Alarm Admin User Guide

As an **Alarm Admin**, you set up the alarm monitoring system — buildings, zones, users, access grants, compliance rules — and you own the audit trail.

## What you can do

- Manage **Buildings** (region, security company, status, assigned tester + approver).
- Configure **Zones** per building (type, area, active state).
- Manage **Alarm Users** (Alarm Testers and Approvers).
- Grant or revoke **User Access** (CSV bulk import supported).
- Set **Compliance Rules** (monthly deadline, SLA, Tier 1/2/3 escalation offsets, biannual cadence).
- View **Compliance** dashboards and the full **Audit Trail**.

## Getting started

1. **Buildings** first — without a building, nothing else works.
2. Add **Zones** — typically 6–20 per building, spread across areas.
3. Create Testers and Approvers under **Alarm Users**.
4. Grant access on **User Access** — one tester per building, one approver (usually shared across buildings).
5. Lock in **Compliance Rules** to drive automated reminders and escalations.

## Tips

- Set a building status to **Exempt** to suppress escalation emails during renovations.
- The audit trail is immutable — every action is recorded with actor + timestamp.
- Tier 3 escalations notify Regional Controller (and DGM for biannual).
